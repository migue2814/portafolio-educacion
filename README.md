# Portafolio docente · Miguel Ángel Cifuentes León

Sitio estático (HTML + CSS + JS en un solo archivo). No necesita instalar nada.

## Archivos
- `index.html` — el portafolio completo
- `foto.png` — tu foto (puedes reemplazarla por una mejor con el mismo nombre)
- `CV_Miguel_Cifuentes_CCSS_DPCC.pdf` — el botón "Descargar CV" apunta a este archivo

## Antes de publicar
1. En `index.html` busca `TU-USUARIO` y cámbialo por tu usuario real de GitHub.
2. (Opcional) Reemplaza `foto.png` por una foto de mayor resolución.

## Publicar en GitHub Pages
1. En GitHub crea un repositorio nuevo, por ejemplo `portafolio-educacion` (público).
2. Sube los tres archivos (botón **Add file → Upload files**).
3. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
4. En uno o dos minutos tu sitio estará en `https://TU-USUARIO.github.io/portafolio-educacion/`.
5. Pon ese enlace en tu CV de educación y, si quieres, en el README de tu perfil de GitHub.
